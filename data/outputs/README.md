# Output Artifacts

This directory contains outputs generated by the training notebook (`training_notebook.ipynb`).

## Files

- `folds.json`: Temporal validation fold definitions for horizon 5 and horizon 10, specifying train origin years, train target years, test origin years, test target years, and calendar overlap windows.
- `forecasts.json`: Point forecasts, conformal prediction intervals, trajectory classes, and top SHAP feature drivers for 4,079 active commercial airports at 2030 (+5 years) and 2035 (+10 years). Synced to `web/forecasts.json` for web map visualization.
- `opportunities.json`: Ranked unserved route opportunities from gravity modeling and link prediction, plus curated high confidence investor risers and tourism destinations. Synced to `web/opportunities.json`.
- `models/`: Directory containing fitted models saved during notebook execution (LightGBM regressors, Ridge models, trajectory classifier, conformal calibration parameters, and benchmark predictions array).
